## 九、原则（写给未来的自己）

```
① 【只增不删】
   任何功能不因"App 没有"或"状态读不到"而移除。
   用户可能已经在用；删除会破坏自动化。

② 【有问题要标注，不要隐藏】
   在本文档和 README 里明确写"⚠️ 命令失败"，
   但实体保留。

③ 【新增功能前先查此表】
   避免重复实现；也避免误删。

④ 【实测才算数】
   "已实现"= 实体存在
   "可用"   = pushState=5 实测通过
```
